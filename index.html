About the data

This site searches public, freely downloadable radio-code datasets. Coverage is partial: no single database covers every car. Read each source's caveats before you rely on a value.

Plain code The stored value is a readable 4-digit code. Ford and Renault tables are generated by an algorithm, not collected from real radios, and haven't been tested against units.
Encoded / unverified The stored value is a raw hex value from a vendor file. It is not a usable radio code and has not been decoded.

Use only for radios you own or are authorised to service. Values are provided as-is, with no guarantee that they are accurate.
