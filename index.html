How it works

Three steps, a few seconds.

  1. 1

    Enter your serial

    Find it on the radio’s label or in the radio’s menu: a serial like VWZ1Z…, a Renault precode like B200, a Ford M123456, or your VIN.

  2. 2

    We detect the brand

    The serial’s prefix tells us the car make and who built the radio, e.g. AUZ2Z → Audi with a Grundig unit. No dropdowns.

  3. 3

    We search every database

    Your key is matched against all databases at once. If it appears in several, you see every match side by side with its source.

About the data

This site searches public, freely downloadable radio-code datasets. Coverage is partial: no single database covers every car.

✓ Plain code The stored value is a readable 4-digit code. Ford and Renault tables are generated by an algorithm, not collected from real radios.
⚠ Encoded / unverified The stored value is a raw hex value from a vendor file. It is not a usable radio code and has not been decoded.

Use only for radios you own or are authorised to service. Values are provided as-is, with no guarantee that they are accurate.
